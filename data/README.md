# Reference datasets

The City of Sydney address and public-housing CSVs live here. They are reference
resources, separate from the live Microburbs API and private rental artifacts.
Neither extension packaging nor Vercel deployment includes this directory.

The historical evaluation evidence in `reports/` retains the original `assets/`
paths and source fingerprints recorded when those checks ran. The energy import
documented in `docs/data-api.md` also records its original `assets/example.csv`
source; that CSV is not checked into this repository.
